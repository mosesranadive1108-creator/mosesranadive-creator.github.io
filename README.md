# Moses Ranadive — Resource Lab

A free, static, responsive resource library designed for GitHub Pages.

## Publish

1. Sign in to GitHub as `mosesranadive1108-creator`.
2. Create a **public** repository named exactly `mosesranadive1108-creator.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, and `resources.js` to the **root** of the repository (not inside a subfolder). Commit the files.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Once deployed, visit **https://mosesranadive1108-creator.github.io**. Deployment can take a few minutes.

## Customize resources

Edit `resources.js`. Each item has `title`, `description`, `category`, `url`, `icon`, and `label`. Supported categories are `AI & Tools`, `Design`, `Prompts`, and `Guides`. You can replace the starter external resources with your own files or links.

To share a PDF, upload it to a `downloads/` folder in the repository and use a URL such as `https://mosesranadive1108-creator.github.io/downloads/your-guide.pdf` (only upload material you have rights to distribute). For large downloads, consider a dedicated file host.

## Notes

- This site is frontend-only; it does not collect visitors' emails or send Instagram DMs.
- Google Fonts requires an internet connection. System fallbacks work offline.
- No paid hosting, framework, or build step required.
